Anything in this file is invisible on the deployed site.

`lib/mdx.ts` filters on `draft`, so this post is excluded from:

- `/blog` and `/blog/[slug]`
- `app/sitemap.ts`
- `app/rss.xml.ts`
- the search index

Set `draft: false` in the frontmatter to publish it.
